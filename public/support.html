使用者支援

Google Calendar 連線、同步與資料刪除說明。

連接 Google Calendar

  1. 先登入 Tracker 帳號。
  2. 展開「連線設定」。
  3. 按「連接 Google Calendar」。
  4. 使用已加入測試使用者或已獲准使用的 Google 帳號完成授權。
  5. 在 Google 同意畫面展開所有服務並確認唯讀 Calendar 權限。
  6. 授權完成後回到 Tracker，按「重新讀取雲端」或「立即同步」。

Calendar 同步失敗

  • 確認 Google Calendar API 已在 Google Cloud 啟用。
  • 確認 OAuth Client ID 與 Supabase callback URI 設定正確。
  • 若授權網址已使用過或停留在錯誤頁，請回到 Tracker 重新開始連線。
  • 若權限或 token 已失效，先解除連線，再重新授權。

解除連線與刪除 Calendar 同步資料

在 Tracker 的「連線設定」按「解除 Google Calendar 連線」。系統會停止存取 Calendar，並刪除 Supabase 中保存的 Calendar connection、OAuth token 與同步快取。

Google Calendar 原始行程不會被刪除。先前保存為 Tracker 讀書紀錄的內容或瀏覽器本機資料可能仍存在；如需刪除雲端資料，請寄信提出要求。

User Support

Instructions for Google Calendar connection, synchronization, and data deletion.

Connect Google Calendar

  1. Sign in to your Tracker account.
  2. Expand “Connection Settings.”
  3. Select “Connect Google Calendar.”
  4. Complete authorization with an approved Google Account or an account added as a test user.
  5. On the Google consent screen, expand all services and confirm the read-only Calendar permission.
  6. After returning to the Tracker, select “Reload Cloud Data” or “Sync Now.”

Calendar Synchronization Problems

  • Confirm that Google Calendar API is enabled in Google Cloud.
  • Confirm that the OAuth client ID and Supabase callback URI are configured correctly.
  • If an authorization URL has already been used or remains on an error page, return to the Tracker and begin the connection again.
  • If the permission or token has expired, disconnect Calendar and authorize it again.

Disconnect and Delete Calendar Synchronization Data

Select “Disconnect Google Calendar” under “Connection Settings.” The Service will stop accessing Calendar and delete the Calendar connection, OAuth tokens, and synchronization cache stored in Supabase.

Original Google Calendar events will not be deleted. Information previously saved as Tracker study records or stored locally in the browser may remain. To request deletion of cloud data, contact support by email.
