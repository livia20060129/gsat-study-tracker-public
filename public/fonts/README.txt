NotoSansTC-Regular.ttf is the wght=400 static instance of NotoSansTC[wght].ttf,
created with fontTools 4.60.1. Glyph coverage is retained.

The font is fetched from this site's own assets only when exporting PDF.
The exported PDF embeds the static font to preserve visible Chinese and Latin glyphs.
