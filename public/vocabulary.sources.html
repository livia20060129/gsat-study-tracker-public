本機 ECDICT 預覽與確認填入

輸入單字後離開英文欄位，即自動帶入查到的 ECDICT 中文翻譯與詞性，不必先按「取得翻譯」。後續仍可修改詞性、新增或刪除各個中文意思；手動內容不會被自動查詢覆蓋。在編輯模式也可按「取得翻譯」查看候選意思，再選擇要追加的內容。未收錄或暫時無法載入時保留英文與手動編輯功能。

Google Cloud Translation 按需翻譯

登入 Tracker 後，可編輯單字、組合或句子的字卡並按「Google 翻譯」，以 Cloud Translation API 將選定英文翻成繁體中文。只送出該段英文；不會自動傳送筆記或整份紀錄，也不會在本機字典查不到時自動轉送。Google 機器翻譯可能有誤，確認預覽後才追加到選定項目及詞性；單一已勾選詞性自動帶入，未標詞性時可參考同拼法本機資料，多種詞性由使用者指定，不由 Google 推測詞性或學測級數。每帳號每月最多 5,000 字元，台灣時間每月 1 日重設。

已保存的 Google 翻譯保留獨立來源標示；有翻譯 PDF、Word 與列印檔包含 Google 標示，無翻譯練習檔不含中文答案。Google 來源不會改標成 ECDICT。資料處理見 隱私權政策，服務及免責說明見 使用者支援。
